Edit, archive, find and share: each tool has its job. Your archive of ordinary files is the shared foundation.

Making it work day to day.

Metadata stays with the pictures.
XMP is an open standard for metadata. Sidecar files store information such as keywords, ratings and editing data. TrueArchive adds to existing XMP files or creates them. Different Nitro edits are retained as variants when the remaining metadata is compatible; other conflicts are reported. Metadata exchange between Nitro, TrueArchive and digiKam has not yet been fully tested with real pictures. More about variants.
digiKam manages the archive.
digiKam is a free, open-source photo manager. Add the archive folder as a collection and enable writing metadata to XMP sidecars. Supported information then remains available outside the digiKam catalogue. Automatic setup by TrueArchive is planned. Configure XMP in digiKam.
Immich is a window into the archive.
Immich is an open-source photo app for your own server. The server needs to be running when you want to view pictures. Mount the archive as a read-only external library; there is no need to upload it again. Immich does not display every XMP field or Nitro editing recipe. Use the finished pictures for viewing. An automatic TrueArchive connector is not available yet. External libraries in Immich.
A second backup protects against loss.
Another view in digiKam or Immich is not a backup. Back up the archive independently and check that files can be restored. For Immich, also back up its database and own files, including user and album information. Scheduled Hetzner backups through TrueArchive are a planned module. Back up Immich.

You can use other tools too. Old drives, additional folders and manual Google Photos exports can also be sources for TrueArchive. The programs are installed separately; this workflow is not an all-in-one package.
